# java-laba-4

## Описание проекта
Проект демонстрирует применение обобщенного программирования (Generics) и функциональных интерфейсов в Java. Реализует работу с коллекциями, контейнерами для хранения объектов и операциями преобразования данных.

## Структура проекта

**Основные пакеты:**
- Главный класс `Main` - система меню для демонстрации всех заданий
- Утилитарные классы для работы с коллекциями
- Функциональные интерфейсы
- Классы-контейнеры

## Задание 1: Обобщенный контейнер Box<T>

### Класс 1: Box<T>
Универсальный контейнер для хранения одного объекта любого типа

**Свойства:**
- `item` (private T) - хранимый объект

**Конструкторы:**
- `Box()` - создает пустую коробку

**Методы:**
- `put(T item)` - помещает объект в коробку (бросит исключение если коробка не пустая)
- `extract()` - извлекает объект из коробки (коробка становится пустой)
- `full()` - проверяет, пустая ли коробка
- `toString()` - строковое представление состояния коробки

**Тестирование:**

Достали: 3

Коробка после доставания: Коробка пустая!

Введите число для хранения в коробке: 

5

Коробка пуста: false

Достали: 5

## Задание 2: Хранилище с альтернативным значением

### Класс 1: Storage<T>
Хранилище с основным и альтернативным значением

**Свойства:**
- `item` (final T) - основной объект
- `alternative` (final T) - альтернативный объект

**Конструкторы:**
- `Storage(T item, T alternative)` - создает хранилище с указанными значениями

**Методы:**
- `getItem()` - возвращает основной объект, если он не null, иначе альтернативный
- `extract()` - извлекает и выводит значение
- `toString()` - строковое представление хранилища
- `input(String el)` - статический метод для преобразования строки в нужный тип

**Тестирование:**

Извлеченное значение: 99

Извлеченное значение: default

Хранилище содержит: hello

Извлеченное значение: hello

Введите объект (или 'null' для null): 

2

Введите альтернативный объект: 

3

## Задание 3: Ковариантность контейнеров

### Класс 1: BoxPoint
Утилита для работы с коробками точек

**Методы:**
- `putPointInBox(Box<? super Point> box, Scanner scanner)` - помещает точку в коробку 

**Особенности:**
- Использует `<? super Point>` для обеспечения ковариантности
- Работает с любыми коробками, которые могут содержать Point или его супертипы

**Тестирование:**

Введите координату Y: 2,25

Введите координату Z: 3,734

В коробку помещена точка с координатами: {2.0;2.25;3.734}

## Задание 7: Пользовательская агрегация коллекций

### Интерфейс 1: Collector<P, T>
Функциональный интерфейс для создания коллекций

**Методы:**
- `P createCollection()` - создает новую коллекцию

### Интерфейс 2: Accumulator<P, T>
Функциональный интерфейс для добавления элементов в коллекцию

**Методы:**
- `void accumulate(P collection, T value)` - добавляет значение в коллекцию

### Класс 1: CollectionUtils
Для пользовательской агрегации коллекций

**Методы:**

## Вспомогательные классы

### Класс 1: Valid
Для валидации ввода

**Методы:**
- `isNumber(String str)` - проверяет что строка состоит только из цифр
- `isValidInteger(String str)` - проверяет что строка является целым числом
- `isValidPositiveInteger(String str)` - проверяет что строка является положительным целым числом

### Класс 2: Point / Points
**Назначение:** Классы для работы с точками (унаследованы из предыдущих лабораторных)
- `Point` - точка в 2D пространстве
- `Points` - точка в 3D пространстве (наследуется от Point)

## Особенности реализации

### 1. Принципы Generics:
- **Параметризация типов** - все утилиты работают с произвольными типами
- **Ограничения wildcards** - `<? super Point>` для ковариантности

### 2. Функциональное программирование:
- **Функциональные интерфейсы** - `Function`, `Predicate`, `Reduce`, `Collector`, `Accumulator`

### 3. Обработка ошибок и валидация:
- Проверка на `null` во всех утилитах
- Валидация пользовательского ввода
- Защита от некорректных данных
