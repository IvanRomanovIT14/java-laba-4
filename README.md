# java-laba-4

Лабораторную работу выполнил Романов Иван ИТ-14

## Описание проекта
Проект представляет собой комплексную систему утилитных классов, демонстрирующих принципы обобщенного программирования (Generics) и функциональных интерфейсов в Java. Включает реализации основных паттернов функционального программирования: преобразование, фильтрация, свертка и коллекционирование данных. Все задачи объединены в единую систему с интерактивным меню для демонстрации функциональности.

## Структура проекта

### Основные функциональные интерфейсы:
- `Function<T, R>` - преобразование элементов
- `Predicate<T>` - фильтрация элементов  
- `Reduce<T>` - свертка элементов
- `Collector<P, T>` - создание коллекций
- `Accumulator<P, T>` - накопление элементов

### Утилитные классы:
- `Transform` - операции преобразования
- `Filter` - операции фильтрации
- `Reducer` - операции свертки
- `CollectionUtils` - операции коллекционирования
- `Box<T>` - обобщенный контейнер
- `Storage<T>` - хранилище с альтернативным значением

### Вспомогательные классы:
- `Valid` - валидация входных данных
- `BoxPoint` - работа с точками через дженерики
- `Point`, `Points` - геометрические точки (из предыдущих работ)

## Задание 1: Обобщенный контейнер Box<T>

### Класс: Box<T>
Универсальный контейнер для хранения одного объекта с контролем состояния.

**Свойства:**
- `item` (private T) - хранимый объект

**Конструкторы:**
- `Box()` - создает пустую коробку

**Методы:**
- `put(T item)` - помещает объект в коробку (только если пустая)
- `extract()` - извлекает объект из коробки
- `full()` - проверяет, пуста ли коробка
- `toString()` - строковое представление состояния

**Тестирование:**
```
Достали: 3
Коробка после доставания: Коробка пустая!
```

---

## Задание 2: Хранилище с альтернативным значением Storage<T>

### Класс: Storage<T>
Хранилище, которое возвращает альтернативное значение при отсутствии основного.

**Свойства:**
- `item` (final T) - основной объект
- `alternative` (final T) - альтернативный объект

**Конструкторы:**
- `Storage(T item, T alternative)` - создает хранилище с указанными значениями

**Методы:**
- `getItem()` - возвращает item или alternative если item = null
- `extract()` - извлекает и выводит значение
- `toString()` - строковое представление содержимого
- `input(String el)` - статический метод преобразования строки в нужный тип

**Тестирование:**
```
Хранилище содержит: 0
Извлеченное значение: 0

Хранилище содержит: 99
Извлеченное значение: 99

Хранилище содержит: default
Извлеченное значение: default

Хранилище содержит: hello
Извлеченное значение: hello

Введите объект (или 'null' для null): null
Введите альтернативный объект: 100
Хранилище содержит: 100
Извлеченное значение: 100
```

## Задание 3: Работа с точками через дженерики

### Класс: BoxPoint
Утилитный класс для работы с точками через обобщенные контейнеры.

**Методы:**
- `putPointInBox(Box<? super Point> box, Scanner scanner)` - помещает точку в коробку

**Тестирование:**
```
Введите координату X: 1.5
Введите координату Y: 2.5  
Введите координату Z: 3.5
В коробку помещена точка с координатами: {1.5;2.5;3.5}
```

## Задание 4: Преобразование элементов (Transform)

### Класс: Transform
Утилитный класс для преобразования элементов коллекции с помощью функции.

**Методы:**
- `transform(List<T> list, Function<T, R> function)` - преобразует каждый элемент списка

**Примеры использования:**

**1. Строки → длины строк:**
```
Исходные: [qwerty, asdfg, zx]
Результат: [6, 5, 2]
```

**2. Числа → абсолютные значения:**
```
Исходные: [1, -3, 7]
Результат: [1, 3, 7]
```

**3. Массивы → максимальные значения:**
```
Исходные массивы: [[1, 2, 3], [-1, -5, 0], [10, 20, 5]]
Максимальные значения: [3, 0, 20]
```

**Интерактивное тестирование:**
Пользователь может выбрать тип преобразования и ввести свои данные для демонстрации работы.

## Задание 5: Фильтрация элементов (Filter)

### Класс: Filter
Утилитный класс для фильтрации элементов коллекции по предикату.

**Методы:**
- `filter(List<T> list, Predicate<T> predicate)` - фильтрует элементы списка

**Примеры использования:**

**1. Фильтрация строк по длине:**
```
Исходные: [qwerty, asdfg, zx]
Результат: [qwerty, asdfg]
```

**2. Фильтрация положительных чисел:**
```
Исходные: [1, -3, 7]
Результат: [1, 7]
```

**3. Фильтрация массивов без положительных элементов:**
```
Исходные массивы: [[1, 2, 3], [-1, -5, 0], [-10, -20, -5]]
Массивы без положительных элементов: [[-1, -5, 0], [-10, -20, -5]]
```

**Интерактивное тестирование:**
Пользователь может выбрать тип фильтрации и ввести свои данные.

## Задание 6: Свертка элементов (Reducer)

### Класс: Reducer
Утилитный класс для свертки (редукции) элементов коллекции.

**Методы:**
- `reduce(List<T> list, Reduce<T> reducer, T initialValue)` - сворачивает элементы списка

**Примеры использования:**

**1. Конкатенация строк:**
```
Исходные: [qwerty, asdfg, zx]
Результат: qwertyasdfgzx
```

**2. Сумма чисел:**
```
Исходные: [1, -3, 7]
Результат: 5
```

**3. Общее количество элементов в списках:**
```
Исходные списки: [[1, 2, 3], [4, 5], [6, 7, 8, 9]]
Общее количество элементов: 9
```

**4. Работа с пустым списком:**
```
Пустой список: []
Результат: default
```

**Интерактивное тестирование:**
Пользователь может выбрать операцию свертки и ввести свои данные.

## Задание 7: Коллекционирование элементов (CollectionUtils)

### Класс: CollectionUtils
Утилитный класс для сложных операций с коллекциями.

**Методы:**
- `collect(List<T> list, Collector<P, T> collector, Accumulator<P, T> accumulator)` - собирает элементы в коллекцию

**Примеры использования:**

**1. Разбиение чисел на группы:**
```
Исходные числа: [1, -3, 7, -2, 0, 5]
Положительные: [1, 7, 5]
Отрицательные: [-3, -2]
Нули: [0]
```

**2. Группировка строк по длине:**
```
Исходные строки: [qwerty, asdfg, zx, qw]
Группировка по длине:
  Длина 2: [zx, qw]
  Длина 5: [asdfg]
  Длина 6: [qwerty]
```

**3. Уникальные строки:**
```
Исходные строки: [qwerty, asdfg, qwerty, qw]
Уникальные строки: [qwerty, asdfg, qw]
```

**Интерактивное тестирование:**
Пользователь может выбрать тип группировки и ввести свои данные.

## Вспомогательные классы

### Класс: Valid
Утилитный класс для валидации входных данных.

**Методы:**
- `isNumber(String str)` - проверяет, состоит ли строка только из цифр
- `isValidInteger(String str)` - проверяет целое число (с учетом знака)

## Особенности реализации

### 1. Принципы дженериков:
- **Параметризация типов:** Все утилитные классы работают с произвольными типами
- **Type safety:** Компиляторная проверка типов для предотвращения ошибок


### 2. Обработка ошибок и валидация:
- Проверка на null и пустые коллекции
- Валидация пользовательского ввода через класс Valid
- Защита от некорректных операций (например, попытка положить объект в заполненную Box)
