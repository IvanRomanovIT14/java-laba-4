# java-laba-4

Лабораторную работу выполнил Романов Иван ИТ-14

## Описание проекта
Проект демонстрирует применение обобщенного программирования (Generics) и функциональных интерфейсов в Java. Включает реализацию различных утилит для работы с коллекциями, контейнеров для хранения объектов и операций преобразования данных с использованием лямбда-выражений.

## Структура проекта

**Основные пакеты:**
- Главный класс `Main` - система меню для демонстрации всех заданий
- Утилитарные классы для работы с коллекциями
- Функциональные интерфейсы
- Классы-контейнеры

## Задание 1: Обобщенный контейнер Box<T>

### Класс 1: Box<T>
**Назначение:** Универсальный контейнер для хранения одного объекта любого типа

**Свойства:**
- `item` (private T) - хранимый объект

**Конструкторы:**
- `Box()` - создает пустую коробку

**Методы:**
- `put(T item)` - помещает объект в коробку (бросит исключение если коробка не пустая)
- `extract()` - извлекает объект из коробки (коробка становится пустой)
- `full()` - проверяет, пустая ли коробка
- `toString()` - строковое представление состояния коробки

**Тестирование:**
```
Достали: 3
Коробка после доставания: Коробка пустая!
Введите число для хранения в коробке: 5
Коробка пуста: false
Достали: 5
```

## Задание 2: Хранилище с альтернативным значением

### Класс 1: Storage<T>
**Назначение:** Хранилище с основным и альтернативным значением

**Свойства:**
- `item` (final T) - основной объект
- `alternative` (final T) - альтернативный объект

**Конструкторы:**
- `Storage(T item, T alternative)` - создает хранилище с указанными значениями

**Методы:**
- `getItem()` - возвращает основной объект, если он не null, иначе альтернативный
- `extract()` - извлекает и выводит значение
- `toString()` - строковое представление хранилища
- `input(String el)` - статический метод для преобразования строки в нужный тип

**Тестирование:**
```
Хранилище содержит: 0
Извлеченное значение: 0
Хранилище содержит: 99
Извлеченное значение: 99
Хранилище содержит: default
Извлеченное значение: default
Хранилище содержит: hello
Извлеченное значение: hello
```

## Задание 3: Ковариантность контейнеров

### Класс 1: BoxPoint
**Назначение:** Утилита для работы с коробками точек

**Методы:**
- `putPointInBox(Box<? super Point> box, Scanner scanner)` - помещает точку в коробку используя lower bounded wildcard

**Особенности:**
- Использует `<? super Point>` для обеспечения ковариантности
- Работает с любыми коробками, которые могут содержать Point или его супертипы

## Задание 4: Преобразование коллекций

### Интерфейс 1: Function<T, P>
**Назначение:** Функциональный интерфейс для преобразования значений

**Методы:**
- `P apply(T item)` - применяет функцию к элементу

### Класс 1: Transform
**Назначение:** Утилита для преобразования элементов коллекции

**Методы:**
- `<T, R> List<R> transform(List<T> list, Function<T, R> function)` - преобразует список с помощью функции

**Тестирование:**
```
1. Строки - длины строк:
   Исходные: [qwerty, asdfg, zx]
   Результат: [6, 5, 2]
2. Числа - абсолютные значения:
   Исходные: [1, -3, 7]
   Результат: [1, 3, 7]
3. Массивы - максимальные значения:
   Исходные массивы: [[1, 2, 3], [-1, -5, 0], [10, 20, 5]]
   Максимальные значения: [3, 0, 20]
```

## Задание 5: Фильтрация коллекций

### Интерфейс 1: Predicate<T>
**Назначение:** Функциональный интерфейс для проверки условий

**Методы:**
- `boolean test(T value)` - проверяет условие для элемента

### Класс 1: Filter
**Назначение:** Утилита для фильтрации элементов коллекции

**Методы:**
- `<T> List<T> filter(List<T> list, Predicate<T> predicate)` - фильтрует список по условию

**Тестирование:**
```
1. Фильтрация строк (длина >= 3):
   Исходные: [qwerty, asdfg, zx]
   Результат: [qwerty, asdfg]
2. Фильтрация положительных чисел:
   Исходные: [1, -3, 7]
   Результат: [1, 7]
3. Фильтрация массивов без положительных элементов:
   Исходные массивы: [[1, 2, 3], [-1, -5, 0], [-10, -20, -5]]
   Массивы без положительных элементов: [[-1, -5, 0], [-10, -20, -5]]
```

## Задание 6: Свертка коллекций

### Интерфейс 1: Reduce<T>
**Назначение:** Функциональный интерфейс для операций свертки

**Методы:**
- `T reduce(T accumulator, T current)` - объединяет два значения

### Класс 1: Reducer
**Назначение:** Утилита для свертки (reduce) элементов коллекции

**Методы:**
- `<T> T reduce(List<T> list, Reduce<T> reducer, T start)` - объединяет все элементы в один результат

**Тестирование:**
```
1. Объединение строк:
   Исходные: [qwerty, asdfg, zx]
   Результат: qwertyasdfgzx
2. Сумма чисел:
   Исходные: [1, -3, 7]
   Результат: 5
3. Общее количество элементов во всех списках:
   Исходные списки: [[1, 2, 3], [4, 5], [6, 7, 8, 9]]
   Общее количество элементов: 9
4. Тест с пустым списком:
   Пустой список: []
   Результат: :)
```

## Задание 7: Пользовательская агрегация коллекций

### Интерфейс 1: Collector<P, T>
**Назначение:** Функциональный интерфейс для создания коллекций

**Методы:**
- `P createCollection()` - создает новую коллекцию

### Интерфейс 2: Accumulator<P, T>
**Назначение:** Функциональный интерфейс для добавления элементов в коллекцию

**Методы:**
- `void accumulate(P collection, T value)` - добавляет значение в коллекцию

### Класс 1: CollectionUtils
**Назначение:** Утилита для пользовательской агрегации коллекций

**Методы:**
- `<T, P> P collect(List<T> list, Collector<P, T> collector, Accumulator<P, T> accumulator)` - создает коллекцию и добавляет элементы

**Тестирование:**
```
1. Разбиение чисел на положительные и отрицательные:
   Исходные числа: [1, -3, 7, -2, 0, 5]
   Положительные: [1, 7, 5]
   Отрицательные: [-3, -2]
   Нули: [0]
2. Группировка строк по длине:
   Исходные строки: [qwerty, asdfg, zx, qw]
   Группировка по длине:
     Длина 2: [zx, qw]
     Длина 5: [asdfg]
     Длина 6: [qwerty]
3. Уникальные строки:
   Исходные строки: [qwerty, asdfg, qwerty, qw]
   Уникальные строки: [qwerty, asdfg, qw]
```

## Вспомогательные классы

### Класс 1: Valid
**Назначение:** Утилита для валидации ввода

**Методы:**
- `isNumber(String str)` - проверяет что строка состоит только из цифр
- `isValidInteger(String str)` - проверяет что строка является целым числом
- `isValidPositiveInteger(String str)` - проверяет что строка является положительным целым числом

**Назначение:** Классы для работы с точками (унаследованы из предыдущих лабораторных)
- `Point` - точка в 2D пространстве
- `Points` - точка в 3D пространстве (наследуется от Point)

## Особенности реализации

### 1. Принципы Generics:
- **Параметризация типов** - все утилиты работают с произвольными типами
- **Ограничения wildcards** - `<? super Point>` для ковариантности
- **Type safety** - компилятор проверяет корректность использования типов

### 2. Функциональное программирование:
- **Функциональные интерфейсы** - `Function`, `Predicate`, `Reduce`, `Collector`, `Accumulator`
- **Лямбда-выражения** - компактная реализация операций
- **Method references** - `ArrayList::new` в качестве коллектора

### 3. Обработка ошибок и валидация:
- Проверка на `null` во всех утилитах
- Валидация пользовательского ввода
- Защита от некорректных данных

### 4. Паттерны проектирования:
- **Strategy Pattern** - различные алгоритмы через функциональные интерфейсы
- **Factory Method** - создание коллекций через Collector
- **Template Method** - общий алгоритм обработки с подставляемыми операциями

Проект демонстрирует мощь обобщенного и функционального программирования в Java для создания гибких и переиспользуемых компонентов.
